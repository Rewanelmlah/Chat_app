# 💬 Flutter Chat App

## 📜 Overview  
Excited to share my recent project: **Flutter Chat App**! 🚀

Built using the **Flutter** framework, **Flutter Chat App** is a dynamic mobile application designed to facilitate real-time communication between users. With features like instant messaging, user authentication via **Firebase Auth**, and messages stored using **Firebase Firestore**, this app offers a seamless chatting experience for its users.

Available for both **Android** and **iOS** platforms, **Flutter Chat App** is designed to connect people in an engaging and efficient manner. Whether for personal or professional use, this app caters to diverse needs and preferences.

Users can easily:
- Login or create a new account.
- Chat with other users in real-time.

## ✨ Features  
- 🔑 **Firebase Authentication**: Users can securely sign up, log in, and manage their accounts.
- 💬 **Real-Time Messaging**: Send and receive messages instantly.
- 🗂️ **Firestore Database**: All messages are stored and retrieved using Firebase Firestore.
- 📱 **Cross-Platform**: Available for both **Android** and **iOS** platforms.
- 🌙 **User-Friendly UI**: Simple and intuitive interface for easy navigation and communication.

## 🛠️ Technologies Used  
- **Flutter**: For building the cross-platform app.
- **Dart**: Programming language used for Flutter development.
- **Firebase Auth**: For user authentication (login and signup).
- **Firebase Firestore**: For storing and retrieving messages in real-time.
